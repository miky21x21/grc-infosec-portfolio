# Divine Healthcare — Information Security Programme

**Status: not started.** Nothing in this folder yet.

## Planned scenario

A US healthcare provider, scoped to a single facility rather than a health system,
built against the **HIPAA Security Rule** as the regulatory driver and
**NIST CSF 2.0** as the control framework.

The purpose of running a second scenario is contrast. Meridian is an Indian
processor carrying simultaneous Indian and international obligations, and is where
the multi-framework crosswalk lives. Divine Healthcare is a single-jurisdiction
US scenario, which exercises a different problem: depth against one regulation
rather than reconciliation across several.

## Planned structure

The same folder scheme and traceability chain as
[`meridian-infotech/`](../meridian-infotech/), with `DH-` document IDs.
