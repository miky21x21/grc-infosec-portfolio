# grc-infosec-portfolio
Hands-on Information Security & GRC portfolio featuring ISO 27001 ISMS artifacts, SOC 2 control mappings, enterprise risk registers, and TPRM frameworks.

---

### 🎯 Target Role Alignment
This portfolio is constructed to demonstrate baseline operational competency for roles including:
* **Information Security Analyst / Associate**
* **GRC Analyst / Security Compliance Analyst**
* **IT Risk Analyst / Third-Party Risk (TPRM) Analyst**
* **IT Auditor / Associate Cloud Security Analyst**

---

### 📐 Frameworks & Standards Applied
* **ISO/IEC 27001:2022** (Information Security Management System)
* **SOC 2 Type II** (Trust Services Criteria: Security, Confidentiality, Availability)
* **NIST CSF 2.0** (Govern, Identify, Protect, Detect, Respond, Recover)
* **CIS Controls v8**
