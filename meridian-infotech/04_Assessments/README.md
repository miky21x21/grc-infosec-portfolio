Gap assessments, control testing results and findings live here. Each finding
references the control it tests and the risk that control treats.

MIC-GAP-001 is run against a real AWS account rather than a hypothetical
environment, so that findings are produced by a scanner rather than chosen by the
author. It was scoped against risk register version 1.0 and will be re-scoped to
Sextant before fieldwork; against version 2.0 it evidences MIC-R-005, MIC-R-009
and MIC-R-010.

Evidence artifacts (EV-GAP-xxx) are produced during fieldwork and indexed in
[`../05_Evidence/`](../05_Evidence/).
