# 03_Policies

| ID | Artifact | Status |
| :--- | :--- | :--- |
| MIC-POL-002 | [Information security policy](./MIC-POL-002_Information_Security_Policy.md) | Version 1.0, effective 3 November 2026 |
| MIC-POL-001 | [AI use and governance policy](./MIC-POL-001_AI_Use_and_Governance_Policy.md) | Version 1.0, effective 3 November 2026 |
| MIC-STD-001 | Access control standard | Planned |

Each policy and standard traces to the risks it treats in MIC-RSK-001. MIC-POL-001
came ahead of the Statement of Applicability because ISO/IEC 42001 clause 5.2 requires
an AI policy as a foundation of the AI management system, and because four risks
(R-002, R-004, R-008, R-011) depend on it. MIC-POL-002, the top-level information security policy required by ISO/IEC 27001
clause 5.2, followed the Statements of Applicability and lists the topic-specific
standards still to be written. Later standards follow the Statement of Applicability.
