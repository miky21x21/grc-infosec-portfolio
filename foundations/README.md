# Foundations

**These are study notes, not portfolio deliverables.**

They document concepts learned while preparing for CompTIA Security+ and working
through GRC fundamentals. They are kept in the repository because they show
reasoning and are useful reference, but they are not evidence of applied work and
should not be read as such.

The applied work lives in [`meridian-infotech/`](../meridian-infotech/).

| File | Covers |
| :--- | :--- |
| `Security_Fundamentals_Guide.md` | CIA triad in enterprise operations; threat vs. vulnerability vs. risk; security control classification |
| `Identity_Access_Management_Fundamentals.md` | IAAA model; least privilege and need-to-know; RBAC; MFA; joiner-mover-leaver lifecycle; access reviews |
| `Enterprise_Asset_Inventory_v1.0.xlsx` | A 10-row categorised asset inventory with impact scoring, mapped to ISO 27001 A.5.9 |

MIC-RSK-001 and is not the Meridian asset register. It stays here until it is
